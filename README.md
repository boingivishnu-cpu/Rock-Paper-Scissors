# 🎮 Rock Paper Scissors Game

A modern and interactive **Rock Paper Scissors** web application built using **Python (Flask)**, **HTML**, **CSS**, **JavaScript**, and **Bootstrap 5**. The game allows users to play against the computer, tracks scores, and provides a responsive, user-friendly interface.

---

## 📌 Features

- 🎮 Play Rock, Paper, or Scissors
- 🤖 Random computer choice
- 🏆 Automatic winner detection
- 📊 Live score tracking
- 🔄 Reset game functionality
- 📱 Responsive design
- 🎨 Modern and attractive UI
- ⚡ Fast gameplay without page refresh
- 💻 Built using Flask and JavaScript

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/Rock-Paper-Scissors.git
```

### 2. Go to the project folder

```bash
cd Rock-Paper-Scissors
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

#### Windows

```bash
venv\Scripts\activate
```

#### macOS/Linux

```bash
source venv/bin/activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python app.py
```

### 7. Open your browser

```
http://127.0.0.1:5000
```
